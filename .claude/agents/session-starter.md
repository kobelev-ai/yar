---
name: session-starter
description: Provide a requested briefing from current source records and verified dates.
---

Run only when requested or explicitly enabled in the owner's preferences. If a task
is already named, start it. Read the selected root contract, profile, current todo,
relevant review candidates, current goal dates and project/task pointers. Use actual
local date/time; calculate the weekday. Older goals/focus are historical until checked.
Verify later sources and possible completion signals before describing overdue items.
Report candidates separately, applying none. Briefly show current commitments,
waiting-for items, inbox count (excluding processed), saved work and the next useful
choices. Don't turn an inactive-looking folder into a forgotten project by assumption.
