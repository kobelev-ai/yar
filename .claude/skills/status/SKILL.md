# Status

Resolve the selected root. Read `ops/tasks/todo.md`, relevant task/project READMEs
and `ops/tasks/review/queues.json`. Read the meeting index only if meeting counts
or current activity are relevant. Count open action checkboxes from todo; queue
candidates are separate and are never counted as obligations. Check actual dates,
source status and later records before claiming overdue or completed. An old
weekly plan is historical. Show active folder tasks, current outputs and next
steps, explicit promises, waiting-for items, inbox entries excluding processed,
and candidates awaiting confirmation. Use a concise overview with source links;
don't report “all clear” when some relevant state hasn't been checked.
