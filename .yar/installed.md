## Format (for reference)

Each installed package is recorded below with a dedicated section:

```markdown
## <recipe_id> v<version>
- **Installed:** YYYY-MM-DD
- **Source:** <who sent the recipe / "manual">
- **Prerequisites:** <list, all checked>
- **Behavior config:** see context/me/preferences.md section "<recipe_id>"
- **Files changed:** <list of files created or modified>
- **MCP servers added:** <list if any>
- **Scripts added:** <list if any>
- **Status:** active | failed | uninstalled | cancelled
```

Status values:
- `active` — installed and working
- `failed` — installation aborted mid-way (see "completed steps")
- `uninstalled` — removed via /pkg_uninstall
- `cancelled` — owner cancelled during install
